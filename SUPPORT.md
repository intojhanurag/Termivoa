# Getting help with Termivoa

| You want to | Go here |
| --- | --- |
| Learn how to install or use Termivoa | [Docs](https://termivoa.com/docs/) and [Troubleshooting](https://termivoa.com/docs/reference/troubleshooting/) |
| Ask a question or share an idea | [GitHub Discussions](https://github.com/intojhanurag/Termivoa/discussions) |
| Report a bug | [Bug report](https://github.com/intojhanurag/Termivoa/issues/new?template=bug.yml) |
| Ask for a feature | [Feature request](https://github.com/intojhanurag/Termivoa/issues/new?template=feature.yml) |
| Report a security problem | Privately, as described in [SECURITY.md](SECURITY.md). Never in a public issue. |

Before you open an issue, run `pterm doctor` (read-only; it never prints
secrets) and search the existing issues.

Never post credentials, pairing links or QR codes, tokens, private code or
real terminal history.

Termivoa is a free, one-person open-source project. Help is best effort.
