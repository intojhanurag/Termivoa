# P6 preparation: startup registration, lifecycle commands, unsigned packaging

Date: 2026-09-27. Branch `feat/p6-packaging`, base `eb8421a`. Artifacts built at
`f411e48`. Apple Silicon macOS 26.5.2, Go 1.27.1, Node 24.11.0.

Nothing was registered on this Mac: no `launchctl bootstrap/bootout`, no file
in `~/Library/LaunchAgents`, no PATH change, no Tailscale change, no signing,
no production broker started. Startup install/uninstall ran only against
temporary directories with injected fake `launchctl` runners.

## Implemented

- `internal/lifecycle`: LaunchAgent plists (`dev.phone-terminal.broker` /
  `.gateway`, `RunAtLoad`, `KeepAlive{SuccessfulExit=false}`,
  `ProcessType=Interactive`, logs in `<data>/logs/<name>.log`) and per-user
  Scheduled Task XML (logon trigger for the user, `InteractiveToken`,
  `LeastPrivilege`, `Hidden`, restart every minute on failure, no time limit,
  `IgnoreNew`, `conhost.exe --headless`, UTF-16LE with BOM). Install/uninstall
  plans (`launchctl bootstrap gui/<uid>` / `bootout`; `schtasks /Create /XML /F`,
  `/Run`, `/End`, `/Delete /F`) applied through an injected runner. Paths with
  control characters, invalid UTF-8, quotes (Windows) or relative form are
  rejected, so XML escaping never silently changes a path. Data deletion only
  accepts directories named `Phone Terminal`.
- Commands: `pterm setup [--apply] [--yes]`, `pterm doctor`,
  `pterm uninstall [--dry-run] [--yes] [--delete-data]`, `pterm launch [--no-open]`,
  `pterm up --dev [--data-dir] [--runtime-dir] [--listen]`.
  Replacing or removing a registered broker is refused while the broker lists
  starting/running/exiting sessions (uses the existing session-list RPC).
- `packaging/macos`: `build-app.sh`, `build-dmg.sh`, `sign-and-notarize.sh`,
  Go bundle launcher. `packaging/windows`: `phone-terminal.iss`,
  `build-installer.ps1`, `sign.ps1`. `.github/workflows/packaging.yml`.
- Docs: `docs/install.md`.
